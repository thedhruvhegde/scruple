# @scruple/client

typed fetch client for the scruple http api, plus a small mcp stdio client for the
dispute simulator. node 20+ (uses global `fetch`). not published: no licence yet
(see `LICENSE-PENDING.md` at the repo root), so `package.json` is `private`.

## build and test

```
npm ci
npm test                                 # tsc, then node:test against a mocked fetch
SCRUPLE_SDK_INTEGRATION=1 npm test       # also a real `scruple serve` and `scruple mcp sim` (needs uv)
npm run check-generated                  # src/schema.ts matches openapi.json
```

## types

- `src/schema.ts` is generated by `openapi-typescript` from `openapi.json`, a snapshot of the
  server's schema. do not edit it.
- after an api change: `uv run python sdk/typescript/scripts/openapi.py` (repo root), then
  `npm run generate`. `tests/test_client_typescript_schema.py` fails until both are done.
- friendly names (`RuleVersion`, `DecisionOut`, `RuleSpec`, ...) are in `src/types.ts`.

## http

```ts
import { Client, ForbiddenError } from "@scruple/client";

// an API key from `scruple keys create`; the server takes the caller's identity from it
const c = new Client({ baseUrl: "http://127.0.0.1:8000", apiKey: process.env.SCRUPLE_API_KEY });
await c.version();
for await (const rule of c.iterRules(100)) console.log(rule.rule_id, rule.status);
```

- auth: `apiKey` goes out as `X-API-Key` on every request. `actor` (sent as `X-Actor`)
  only works against a server in the development-only mode
  (`SCRUPLE_AUTH_DEV_ACTOR_HEADER=true`).
- errors: `ApiError` with `status`, `detail`, `requestId`; subclasses `BadRequestError`,
  `UnauthorizedError`, `ForbiddenError`, `NotFoundError`, `ConflictError`, `ValidationError`, `RateLimitedError`,
  `ServerError`. no response at all: `TransportError`.
- retries: GET only, on network errors and 429/502/503/504, backoff 250 ms doubling to 8 s,
  `Retry-After` honoured. POST is never retried, so an evaluation or approval cannot run twice.
- paging: `rules({ limit, offset })`, `iterRules(pageSize)`, `iterDecisions(ruleId, pageSize)`,
  driven by the server's `X-Total-Count` header.

## mcp (dispute episodes)

```ts
import { McpStdioClient } from "@scruple/client/mcp";

const sim = await McpStdioClient.spawn("scruple", ["mcp", "sim"]);
const { episode_id } = await sim.callTool("start_dispute_episode", { seed: 7 });
```

## examples

- `examples/gate-flow.ts`: propose, evaluate, approve, report, verify. it acts as two
  people, so `npm run example:http` needs `SCRUPLE_AUTH_DEV_ACTOR_HEADER=true uv run scruple serve`.
- `examples/dispute-episode.ts`: one synthetic dispute through the mcp simulator with an
  evidence policy. `npm run example:mcp`.
