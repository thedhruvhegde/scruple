01 / HOW IT WORKSTest what an agent learned before it touches money.

A simulator and a set of verifiers for agents that move money. Every stage is deterministic and leaves a record.

  • SimulateSeeded disputes and a double-entry ledger, 8 case types.
  • VerifyCost read from ledger postings, scored per case type.
  • GateReplay, canary, a named approver, rollback.

Train on it.Evaluate on it.Ship through it.

04 / WHO IT'S FOROne loop, three buyers.

The same environments and verifiers train an agent, test its releases, and give a bank evidence to approve it.

  • AI labsTrain agents on money workflows with rewards they cannot game.
  • BuildersTest every release of a finance agent against the same cases.
  • BanksApprove agent changes with evidence a model-risk reviewer can read.

Today: simulator, verifiers, gate for learned rules. Next: step-by-step RL environments, model and prompt changes.
