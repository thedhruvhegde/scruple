RL environments · verifiers · release gate

RL environments and release gates for AI agents that move money.

A seeded card-dispute simulator, 20 verifiers that score from the ledger and check the agent's own report against it, and a CI gate that blocks a release if any case type gets worse.

01 / HOW IT WORKSTest what an agent learned before it touches money.

A simulator and a set of verifiers for agents that move money. Every stage is reproducible from its seed and leaves a record.

  • SimulateSeeded disputes on a double-entry ledger: 6 hidden case types across Visa and Mastercard reason codes.
  • Verify20 checks score cost from ledger postings, per case type, and check the agent's report against them.
  • GateReplay, canary, a named approver, rollback.

Train on it.Evaluate on it.Ship through it.

02 / PROOFThe average said yes. One case type said no.

Two learned rules with the same condition. The bad one lowered the average loss by $10.94 a case, and made late-evidence disputes worse. Blocked.

03 / RED TEAMSeven ways to cheat. None got through.

Each attack had to fool a naive verifier first, so we know it is a real attack.

  • Improve the average, break a rare caseBlocked
  • Accept small disputes, refund twiceBlocked
  • Escalate everything to humansBlocked
  • Memorize training casesHeld
  • Report zero lossIgnored

04 / WHO IT'S FOROne loop, three buyers.

The same environments and verifiers train an agent, test its releases, and give a bank evidence to approve it.

  • AI labsTrain agents on money workflows with rewards they cannot game.
  • BuildersTest every release of a finance agent against the same cases.
  • BanksApprove agent changes with evidence a model-risk reviewer can read.

Today: the dispute RL environment, 20 verifiers and the release gate. Next: more money workflows, and gating model and prompt changes end to end.
